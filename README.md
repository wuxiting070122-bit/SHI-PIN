# TV TOWER · 拾频

基于真实电视塔 GLB 的交互式作品集原型。Vite + Three.js + GSAP，无后端。

> 在线演示：https://61340197ab2a43758aa51e7e6a9af9d6.app.workbuddy.host
> 面向评审的项目导读见 [PORTFOLIO.md](PORTFOLIO.md)；素材来源与授权见 [ASSET_SOURCES.md](ASSET_SOURCES.md)。

## 本地运行

```sh
npm install
npm run dev
```

打开终端打印的地址（默认 http://127.0.0.1:5173）。不要直接双击 index.html。

```sh
npm test
npm run build
npm run preview
```

构建结果在 `dist/`，可以放到静态网站托管服务。项目采用相对 base，可托管在子目录。当前已有在线演示（见顶部链接）。

VS Code 已提供任务：菜单“终端 → 运行任务 → 启动作品集预览”。代码改动由 Vite 自动刷新。

## 已实现

- AI 生成的少女持相机开场插画，屏幕点击热区、推近与雪花切换，以及跳过开场。
- 真实 GLB 字节下载进度、解析阶段提示、错误重试、图形不可用时的作品目录入口。
- 23 块可点击屏幕，真实遮挡检测，拖拽与点击区分。
- 第一人称观察：拖动或方向键原地转头；滚轮、W/S 和底部箭头沿闭合路径行走；手机单指观察、双指滑动行走。
- 人眼高度与视线分开控制，地面、电线和远景支架提供运动视差。主场景无大标题和常驻操作文案，功能收进右上角菜单。
- 点击先转向，再沿塔外安全路径靠近屏幕；按屏幕几何与视口比例调整观察距离。取消或关闭详情后沿原路径返回，保留位置与视线。
- 五个示例分类、十个概念研究条目，完整分类和项目详情、关于与操作说明。
- 聚焦中按 ESC 可取消，详情关闭返回原机位；动画期间锁定场景输入。
- 拍照、取景器合成、相册浏览及 JPEG 下载，最多 12 张，刷新清空。
- 可玩的调频小游戏（游离实验 → 寻找信号）：拖动频率直到信号足够强后锁定，可重玩。
- 默认静音的合成反馈音效；手机布局、键盘焦点、原生对话框焦点约束、减少动态效果偏好。

## 替换内容

- `src/data.js`：分类、项目标题、简介、年份和说明；`channelMap` 将 TV_01～TV_23 绑定到分类。
- 分类可加 `cover: './images/my-cover.webp'`：电视与分类封面使用这张图。
- 单个项目可加 `cover: './images/my-project.webp'`：替换详情和卡片封面。
- 缺少 cover 时，`src/artwork.js` 自动绘制概念封面。示例内容明确标为概念研究，不代表真实项目经历。
- `public/images/photographer.png`：替换开场图片。替换构图后，调整 `src/style.css` 的 `#camera-hotspot`，以及 `src/main.js` 中的 LCD 锚点（当前为图片宽度 29.5%、高度 30.3%）。
- `public/models/retro_tv_stack.glb`：替换电视塔，保留 TV_XX_Screen 命名与 +Z 朝向约定；新模型尺寸变化较大时调整 `src/scene.js` 中主机位与轨道边界。
- `index.html`：品牌、开场文字和常驻界面。
- `src/main.js`：关于文案、详情排版与应用流程。
- `src/style.css`：视觉与响应式布局。
- `src/WalkCamera.js`：转头、行走、点击靠近与反向返回。
- `src/walk-path.js`：固定眼高的闭合路径、聚焦路线和障碍检测。
- `src/environment.js`：地面、电线与远景参照。

## 实现说明与边界

开场使用 2.5D 插画图层和固定 LCD 锚点完成镜头叙事，电视塔部分是真实 WebGL 场景。插画只在开场出现一次，不返回后续画面。

模型约 10.38 MB、18.3 万三角形。当前保留原模型以便先验收视觉；正式上线前建议测量真实手机性能，再选择几何简化与 Draco/Meshopt 压缩，不保证压缩后的固定体积。无视频资源和真实作品素材，当前展示静态概念研究封面。

照片保存在本次浏览的 Blob URL 中，无上传与永久存储。声音由 Web Audio 合成。浏览器尺寸测试不等同于真实手机性能测试。暂未接入持久化相册、真实联系方式、独立作品 URL、跑酷或音游。

原始交接项目位于 WorkBuddy 目录，本项目为独立实现，没有修改原工程。生成提示词见 IMAGE_PROMPT.md。

## 唱片机折页交互

直接预览：`http://127.0.0.1:5173/?scene=record-player`。电视塔的影像叙事分类也会进入此空间。

四片折页分别使用蓝、杏、绿、紫纯色占位。向下滚动逐片展开并切换屏幕，向上反向收折；支持上下拖动、方向键、底部颜色按钮。滚动停下后吸附到整件作品。返回按钮或 Escape 回到电视塔。

实现：`src/record-player.js`；模型：`public/models/record-player.glb`，使用提供的 Blender 文件同目录静态 GLB，保留铰链层级，原始 Blender 文件未改动。本版仅作品选择动画，没有接入实际视频播放。

## 文稿折叠信件

直接预览：`http://127.0.0.1:5173/?scene=letters`。电视塔新增“文稿信件”频道（06），也可从作品目录进入；第 11、23 台电视使用信封封面作为入口。

模型八片折板按相邻两片分成四封信。点击纸面或蓝色编号，旁边滑出简介纸角；再次点击纸角，信纸移至眼前并分段展开，全文支持滚动阅读。右上角收起按钮或 Escape 回到选中的信件；再按 Escape 收起简介，再按返回电视塔。

内容集中在 `src/manuscripts.js` 的 `title / kind / summary / paragraphs`，当前四篇为示例。交互在 `src/letter-space.js`：Three.js 负责模型与点击检测，投影定位简介，GSAP 与 CSS 3D 完成信纸展开，HTML 保证全文清晰与可选择。GLB 来自所提供 Blender 文件同目录的网页版本；原始建模文件未修改。
